# RIGSoC - A RISC-V System-on-Chip for the GateMate FPGA
For a project at my university in Munich, me and my friends Fynn, Timo and Tobi made a FPGA-design of the ibex RISC-V processor 
for the GateMate FPGA from Germany. It uses the demo-system of the ibex processor with some things deletet and some things added by me, so
that it can run good on the GateMate.
A guide on how to install the toolchain and how to use this repository will follow soon!
